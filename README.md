## 🏦 Banking Management System

**Java • Object-Oriented Programming • Software Design**

A banking management project developed as part of my software development and internship experience.

The project focuses on modeling a banking environment through software and applying object-oriented programming concepts to real-world entities and operations.

### 🎯 Project Goal

The main objective was to transform real-world banking concepts into structured software components.

Instead of approaching the project only as a collection of functions, I focused on understanding how entities, operations, and business rules can be represented through object-oriented design.

### 🔧 Key Areas

- Customer and account-oriented system modeling
- Banking operation workflows
- Object-oriented class design
- Business logic implementation
- Input validation
- Exception handling
- Structured application flow
- Modular code organization

### 🧠 Engineering Perspective

The project helped me understand how a real-world domain can be broken down into software components.

I practiced thinking about:

- What each class should represent
- Which responsibilities belong to which component
- How objects interact with each other
- How business rules should be represented
- How invalid operations should be handled
- How a system can remain understandable as its functionality grows

### 📚 What I Learned

The Banking Management System strengthened my understanding of **object-oriented thinking and domain modeling**.

It helped me move from thinking primarily about individual programming tasks toward thinking about the **structure of an entire software system**.

# 🚗 Rent-a-Car System

**Java • OOP • Maven • Gson • JSON • Git**

A structured vehicle rental management system developed around real-world rental operations and business rules.

This project was an important step in developing my understanding of **software architecture, separation of responsibilities, validation, exception handling, DTO design, and data persistence**.

### 🎯 Project Goal

The goal was to build a system capable of managing vehicles and their rental lifecycle while keeping business rules and application responsibilities clearly organized.

Rather than placing all functionality into a single application flow, I structured the system into separate components with specific responsibilities.
